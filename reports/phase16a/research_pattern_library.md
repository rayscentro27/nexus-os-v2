# Phase 16A Research Pattern Library

Generated from existing repository research and implementation audits. The JSON file is canonical; this Markdown is an operator-readable index.

## Decisions

- Reuse the existing Nexus 3 design tokens, responsive shell, journey rail, next-action cards, and visual-fidelity workflow.
- Extend the client portal with real empty-state/data-class guarantees before subjective redesign.
- Use a shared brief/evidence packet for Hermes and Nova; keep client-facing context filtered.
- Treat named Orca, T3 Code, Penpot, Excalidraw, and Granular concepts as `PILOT_LATER`; no standalone canonical artifacts or proven capability gaps were found in the repository audit, so no tools were installed.
- Ray approval is required before selecting a broad visual territory.
