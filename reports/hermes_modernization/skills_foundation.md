## Shared Structure

Each skill documents:

- purpose
- activation criteria
- inputs
- procedure
- allowed tools
- deterministic-first rules
- evidence requirements
- verification
- output format
- escalation
- prohibited actions

## Lifecycle

- DRAFT
- TEST
- VERIFY
- REVIEW
- PROMOTE

## Notes

- Skills are version-controlled under `plugins/nexus-hermes-plugin/skills/`.
- Skills are read-only guidance, not a new authority layer.
