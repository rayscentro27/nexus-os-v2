# Crawl4AI Decision — Phase 13B

Installed: `no`
Pilot: `NOT_RUN`
Decision: `DEFER`

Alpha certification did not expose a measured material gap in the proven public-repository extraction workflow. The Phase 9 pilot already produced compact evidence, provenance, deterministic dedupe, and a canonical opportunity handoff without Crawl4AI. Existing Alpha has a web-search/URL-review foundation and the scout classified Crawl4AI as an equivalent capability to wrap rather than an automatic install.

No public URL pilot was run because the required comparison baseline—existing Alpha extraction versus Crawl4AI for JS rendering, Markdown cleanliness, structured extraction, downstream tokens, duplicate rate, execution time, and failure rate—was not required by a demonstrated current failure. Installing a dependency for novelty would violate the capability-gap gate.

Revisit only when a public-only fixture demonstrates a concrete extraction failure that Crawl4AI can address. Any future pilot must be isolated, open-source/local, no-client-PII, no-paid-plan, and read-only.
