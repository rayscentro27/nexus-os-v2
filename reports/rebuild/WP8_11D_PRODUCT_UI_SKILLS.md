# WP8.11D Product UI Skills

Existing UI review tooling was audited (`scripts/design/review_ui_quality.py`,
the Nexus admin design system, and current Studio components). The Review
Studio applies the bounded service contract directly rather than adding
persistent agents:

- `PRODUCT_UI_DIRECTOR_SKILL=AVAILABLE`
- `UI_UX_VISUAL_CRITIC_SKILL=AVAILABLE`
- `DESIGN_SYSTEM_GUARDIAN_SKILL=AVAILABLE`
- `GOCLEAR_PRODUCT_UX_SKILL=AVAILABLE`
- `GOCLEAR_UX_CONTRACT=PASS`
- `GOCLEAR_PRODUCTION_UI_UNCHANGED=YES`

The preserved UX principles are guided workflow, inline work context, Funding
Readiness as primary destination, useful Hermes visibility, large clear icons,
compact desktop spacing, mobile usability, and no forced Documents-tab loop.
