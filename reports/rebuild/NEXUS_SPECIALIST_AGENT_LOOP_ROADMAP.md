# Nexus Specialist-Agent Loop Roadmap

POST_GOOGLE_SPECIALIST_LOOP_INTEGRATION_REQUIRED=YES

After Nexus current-state certification, Google MCP, and specialist routing,
each specialist must have a formal contract containing:

`ROLE`, `GOAL`, `SKILLS`, `AUTHORIZED_TOOLS`, `BUSINESS_LOOP_RESPONSIBILITIES`,
`TRIGGERS`, `INPUT_CONTRACT`, `OUTPUT_CONTRACT`, `WORK_ORDER_LIFECYCLE`,
`SUCCESS_METRICS`, `ESCALATION_RULES`, `NOVA_RETURN_PATH`, and
`NEXUS_STATE_INTEGRATION`.

Initial roles are Nova, Jax, Alpha, Growth, Creative, and potentially Clyde.
Specialists participate in governed loops; they are not merely chatbots.

Target loop:

`DISCOVER → ALPHA RESEARCH/VERIFY/CHALLENGE/ECONOMICS → NOVA JUDGMENT/PRIORITY
→ GROWTH OFFER/FUNNEL/CAMPAIGN → JAX IMPLEMENTATION → CREATIVE ASSETS
→ NEXUS GOVERNANCE/STATE/APPROVAL/EXECUTION → MEASURE → NOVA INTERPRET
→ OPTIMIZE/CHALLENGE AGAIN`

This is roadmap documentation only. No specialist agents or Google MCP are
implemented in the current campaign.
