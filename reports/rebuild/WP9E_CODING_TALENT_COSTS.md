# WP9E coding-talent cost cards

The candidates' published source licenses are software terms, not runtime
pricing. None bundles inference, compute, storage, bandwidth, free credits, or
a free model. Continue is additionally maintenance-risky because its upstream
README says the repository is no longer actively maintained. API/model cost,
token volume, Oracle allocation limits, and monthly task volume are UNKNOWN
until a candidate and model route are authorized and measured. Thus each is
`USAGE_DEPENDENT`, not “free”.

No installation, subscription, account, or paid commitment was made. The only
defensible incremental cash statement is `MAX_NEW_PAID_COST_USD=0`; that does
not establish zero replacement cost or zero resource consumption.
