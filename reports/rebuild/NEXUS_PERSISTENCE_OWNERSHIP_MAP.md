# Persistence Ownership Map

Durable Nexus/Supabase candidates: goals, work orders, loop state, approvals,
opportunities, campaigns, client state, metrics/outcomes, learnings, strategy
versions, assignments, and receipts/summaries. Local/temporary: raw logs,
debug output, caches, intermediate Python calculations, and unneeded raw tool
payloads. Existing stores are reused; this phase performs no bulk migration.
