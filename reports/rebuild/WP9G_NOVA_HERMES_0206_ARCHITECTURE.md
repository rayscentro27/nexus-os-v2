# WP9G Nova / Hermes 0.20.6 architecture

The safe target is Mac ingress/auth/authority/state/Finance/receipts/Telegram
→ private loopback SSH tunnel → Oracle Hermes 0.20.6 → bounded Nexus read/tool
surfaces → Mac verification and Nova synthesis → Telegram.

Nova identity remains the executive profile; Hermes is the agent runtime; the
model is only the reasoning substrate. The current native Nova profile is
already isolated in `config/hermes/nova-profile/SOUL.md`. No production cutover
was performed because Oracle model execution did not return a result.
