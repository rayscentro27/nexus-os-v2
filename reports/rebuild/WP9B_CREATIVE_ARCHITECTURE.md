# WP9B Creative architecture

`creative/wp9b.py` is the additive canonical boundary. It normalizes
`CreativeBrief`, `CreativeTerritory`, provider routes, structured critic,
revision lineage, render-ready artifacts, Growth handoff, and Finance receipt
around existing Creative Lab/Studio implementations. It is deterministic-first,
idempotent by content fingerprint, internal-only, and has no scheduler or
publication authority.

Flow: Alpha persisted evidence → brief → three distinct territories → selected
territory → channel-native artifact plan → independent critic → new revision
version → Finance receipt → Growth review handoff.

The existing scheduler remains unchanged. The current certification state and
WP9 runtime evidence are not touched.
