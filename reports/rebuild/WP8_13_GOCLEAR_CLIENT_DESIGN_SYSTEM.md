# GoClear Client Design System

The dedicated V2 system in `src/client-v2/styles/v2-theme.css`, generated Tailwind utilities, and V2 primitives provides client-specific typography, spacing, cards, status, journey rail, readiness arc, Hermes panel, upload controls, and responsive states. It does not copy the Operator Console shell. A visual review found the mobile sidebar was stacking above content; it was repaired into a compact horizontal journey rail and re-certified with Playwright.

Product UI Director, GoClear Product UX, Design System Guardian, and UI/UX Visual Critic contracts are reused from WP8.11D/12. The GoClear UX contract retains guided workflow, inline uploads, Funding Readiness as destination, prominent useful Hermes, clear icons, compact desktop, and mobile-first behavior.
