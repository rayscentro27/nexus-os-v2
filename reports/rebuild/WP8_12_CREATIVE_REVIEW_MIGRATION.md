# WP8.12 Creative Review Migration

Operator Console → Creative embeds the existing `CreativeReviewStudio`; it does not create duplicate Creative state. The real Supabase-backed index reports five migrated WP8.11B assets and uses signed remote review references, thumbnails, posters, and proxy-first video. Supported review categories remain Overview, Review Queue, Landing Pages, Images, Videos, Nova, and Archive.

`CREATIVE_REVIEW_MIGRATED_TO_OPERATOR_CONSOLE=YES`; `CREATIVE_REMOTE_MEDIA_BOUND=PASS`; `OPERATOR_CREATIVE_GALLERY=PASS`.
