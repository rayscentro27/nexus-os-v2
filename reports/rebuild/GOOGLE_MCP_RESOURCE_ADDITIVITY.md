# Google MCP Resource Additivity

Google tools remain available through Hermes native discovery without becoming
the default worldview. The clean semantic tests selected Calendar for a
meeting question and Gmail for a recent-email question; casual coffee and
pricing turns selected no resource. Calendar context released before explicit
Nexus selection.

The resource contract is:

`Nova owns the question → optional resource selection → Nova synthesis`.

Google is not a mode, command prefix, classifier branch, or replacement for
Nexus/Web/Alpha.
