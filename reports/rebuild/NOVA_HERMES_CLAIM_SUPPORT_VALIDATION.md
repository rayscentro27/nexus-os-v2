# Hermes Nova claim-support validation

The shadow now supplies claim-support feedback after a tool turn. A retrieved
page does not automatically establish the user's objective. For example, a
financial product page does not prove that an affiliate/referral program
exists. The model is asked to distinguish direct support, partial support, and
unknown evidence and to qualify the answer when the objective is not proven.

Qualified uncertainty such as `not verified`, `no definitive program found`,
or `insufficient evidence` is accepted as truthful language, not treated as a
false unsupported claim. The system does not refuse merely because evidence is
incomplete.
