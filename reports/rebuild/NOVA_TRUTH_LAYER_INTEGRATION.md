# Nova Truth-Layer Integration

Nova already has governed read-only capability access through `capabilities/shared.py`, the semantic capability gate, query planner, provenance store, and current report/runtime adapters. The new company-context view provides low-friction Level-2 context without copying canonical state.

Truth discipline:

- context is advisory and report-backed;
- consequential claims require a current capability result;
- configured, loaded, running, healthy, simulated, and completed remain distinct;
- absence of evidence is not proof of absence;
- Nova cannot write through its capability allowlist;
- approval continuity requires an explicit, scoped decision and TruthKernel resolution.

The existing daily brief is reused as the briefing source. `nova_company_context.py` projects current status, overnight activity, research, operations, Ray attention, blockers, risks, and recommendations while preserving source references and mixed freshness.
