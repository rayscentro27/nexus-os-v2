# WP8.4 Trading Component Map

`MARKET QUESTION -> Alpha research/critique -> strategy hypothesis -> Nexus
strategy version -> deterministic Nexus backtest -> OOS/robustness -> OANDA
Practice paper path -> metrics/receipts -> Alpha interpretation -> Nova review`

| Stage | Owner | Component |
|---|---|---|
| research and challenge | Alpha/Hermes | native Alpha research and bounded Web/MCP |
| state/authority | Nexus | durable work orders, loops, permissions, receipts |
| arithmetic/backtest | Trading Engine | deterministic Python/Nexus backtester |
| paper execution | Trading Engine | existing OANDA Practice guard |
| learning/improvement | Nexus + Alpha | versioned candidates and evidence |
| executive decision | Nova | native synthesis and governed review |

Legacy Vibe-compatible code is a bounded future adapter candidate only.
