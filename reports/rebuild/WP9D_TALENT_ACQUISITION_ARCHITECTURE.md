# WP9D talent acquisition architecture

Talent records use lifecycle states from candidate through trial, active,
degraded, replacement, and retirement. “Hire” means a real bounded integration
and verified work, not installation. Candidate records retain software/model/
compute/storage/network/maintenance cost distinctions and security review.

No candidate was installed or promoted. The capability-gap path is represented
in the Foundry record: capture → classify → research/shape → plan → approval if
needed → delegate → build → verify → present.
