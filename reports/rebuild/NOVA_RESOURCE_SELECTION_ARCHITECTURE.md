# Nova Resource Selection Architecture

The current architecture remains Hermes-native:

`user → Hermes/Nova understands → native answer or semantic resource selection → synthesis`

Nexus MCP is an optional internal resource. Web and Alpha remain separate
resources. Availability does not imply selection, and a prior resource domain
does not become a session mode.

Current observations:

- Nexus tools are available to the bounded runtime on ordinary turns.
- Casual live turns selected no tools.
- Explicit Nexus requests selected Nexus MCP.
- The repaired referent contract scopes only genuine continuations.

This preserves broad intelligence while keeping canonical operational truth in
Nexus and human-facing wording in Hermes.
