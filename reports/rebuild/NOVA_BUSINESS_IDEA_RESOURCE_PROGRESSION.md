# Nova Business-Idea Resource Progression

## Control matrix

The test matrix used the current native Hermes path and kept all resources
available. Explicit Nexus/current-state prompts remain appropriate for Nexus;
self-contained hypothetical advice remains answerable natively. Current public
market questions may use Web/Alpha when the model determines current evidence is
material.

| Prompt class | Expected semantic resource | Result |
|---|---|---|
| Cleaning-business idea evaluation | Native reasoning | Answer remained native; one unnecessary Nexus selection was observed |
| Business-model attractiveness | Native reasoning | No architecture rule requires a resource |
| Subscription-service planning | Native reasoning | No architecture rule requires a resource |
| Fit with what Nexus currently focuses on | Nexus | Nexus is appropriate |
| Active opportunities in Nexus | Nexus | Nexus is required |
| Current market growth/research | Web/Alpha as needed | Distinct from internal Nexus state |

The observed unnecessary call was harmless to the answer and is recorded as a
native selection variance, not suppressed with a keyword rule. The metadata-only
repair makes the resource boundary explicit for future model decisions.

`NOVA_NATIVE_BUSINESS_REASONING=PASS`

`RESOURCE_SELECTION_DISTINGUISHES_REASONING_FROM_RESEARCH=PASS` at the
architecture/metadata contract level. A stochastic model choice does not prove
that resources can be made deterministically unused without violating scope.
