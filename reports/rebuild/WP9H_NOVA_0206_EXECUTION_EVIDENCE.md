# WP9H Nova on Hermes 0.20.6 evidence

The existing Nova profile remains at `config/hermes/nova-profile/SOUL.md` and
the live Telegram worker remains the Mac Hermes path. The Oracle container can
execute a real one-shot Hermes prompt with the OpenRouter profile under an
ephemeral provider-key injection, but there is no durable authenticated Mac
bridge route that loads the Nova profile and returns a governed Nexus context.

Therefore:

- `NOVA_ON_HERMES_0206_PROFILE=NOT_PROVEN_REAL_PROFILE_EXECUTION`.
- `NOVA_CURRENT_COMPANY_CONTEXT=NOT_PROVEN_ON_ORACLE`.
- `ORACLE_HERMES_MCP=NOT_PROVEN_EXECUTION`.
- `ORACLE_HERMES_SKILLS=NOT_PROVEN_EXECUTION`.
- `ORACLE_HERMES_DELEGATION=NOT_PROVEN`.
- `HERMES_BLOCKER_OWNERSHIP=NOT_PROVEN`.

The current Mac Telegram brain was not changed.
