# Nexus/Hermes information source map

| Information | Owner | Currentness | Purpose | Can override current state? |
|---|---|---|---|---:|
| Current operational state | Nexus MCP / canonical currentness | live, capability-specific | present operational answers | yes, when current and eligible |
| Historical business state | Nexus durable research/history sources | historical | prior analysis and trends | no |
| Session context | Hermes session | timestamped conversational context | referents and continuity | no |
| Validated knowledge | Nexus knowledge layer | validation-defined | reusable learned facts | no, unless revalidated for the query |
| Model knowledge | provider/model | general knowledge | explanation and reasoning | no |
| Web | web search/retrieval | retrieval-defined | current public information | only for its supported public claims |
| Alpha | governed research result | result-defined | challenge/verification/economics | only for supported findings |

Nexus owns operational truth and authority. Hermes owns reasoning and final
wording. Langfuse observes provenance but is not a truth store.
