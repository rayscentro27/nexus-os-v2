# WP8.7 Last-30-Days Discovery Architecture

## Contract

`RECENCY_WINDOWS` supports LAST_24_HOURS, LAST_7_DAYS, LAST_30_DAYS, LAST_90_DAYS, and EVERGREEN. The default is LAST_30_DAYS with a UTC cutoff calculated at run time.
## Bound

The cycle uses explicit budgets: MAX_SEARCH_QUERIES=4, MAX_DISCOVERY_RESULTS=12, MAX_YOUTUBE_TRANSCRIPTS=1, MAX_PAGE_FETCHES=4, MAX_GITHUB_REPOS=4, MAX_FORUM_THREADS=2, MAX_RESEARCH_CALLS=8, MAX_AI_CALLS=1, MAX_RUNTIME_SECONDS=180.
