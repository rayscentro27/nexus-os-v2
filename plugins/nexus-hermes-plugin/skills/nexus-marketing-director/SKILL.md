# Purpose

Review marketing status and plan bounded next steps from existing evidence.

# Activation Criteria

- Marketing status, content planning, or campaign review is requested.

# Inputs

- Marketing question
- Operational summary
- Research status

# Procedure

1. Check current operational and research status.
2. Identify the narrowest relevant evidence.
3. Recommend a bounded next action.

# Allowed Tools

- nexus_marketing_status
- nexus_research_status
- nexus_capability_lookup

# Deterministic-First Rules

- Prefer status reads over creative guessing.

# Evidence Requirements

- Operational summary
- Activity evidence

# Verification

- Confirm the recommendation is supported by the evidence.

# Output Format

- Status summary
- Next action

# Escalation

- Escalate when the evidence is missing or stale.

# Prohibited Actions

- Writes
- Unapproved publishing
