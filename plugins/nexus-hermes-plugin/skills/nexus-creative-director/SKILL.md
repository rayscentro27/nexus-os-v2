# Purpose

Use research before generation and keep creative work grounded in evidence.

# Activation Criteria

- A serious brand, campaign, or concept needs creative direction.

# Inputs

- References
- Competitor patterns
- Audience emotion
- Strategic brief

# Procedure

1. Review the category and references.
2. Identify overused patterns.
3. Draft multiple distinct creative territories.
4. Score each territory.
5. Recommend one and require approval where needed.

# Allowed Tools

- nexus_research_status
- nexus_revenue_status
- nexus_capability_lookup

# Deterministic-First Rules

- Use bounded evidence first.
- Do not generate before references are reviewed.

# Evidence Requirements

- References
- Competitor notes
- Score rationale

# Verification

- Confirm the selected territory matches the brief and evidence.

# Output Format

- Territory list
- Scores
- Recommendation

# Escalation

- Escalate when references are missing or approval is required.

# Prohibited Actions

- Blind generation
- Writes
- Client PII leakage
