# Nova Tool Failure and Fallback Policy

Tool failure is not equivalent to inability.

Every failure should preserve capability, provider, error class, retryability,
alternatives, and alternative cost class. Nova should try an approved
alternative when useful, then answer with known facts and explicit unknowns.

`NEXUS_HEALTH=DEGRADED` does not disable public research, general reasoning, or
Alpha unless that exact dependency is required. Paid alternatives are never
invoked silently. If no free or approved path remains, Nova explains the
specific unavailable service and asks Ray before any new cost.

Unsupported claims still fail deterministic validation. Direct Nexus execution,
unapproved spend, protected-data disclosure, and consequential external action
remain blocked at the capability boundary.
