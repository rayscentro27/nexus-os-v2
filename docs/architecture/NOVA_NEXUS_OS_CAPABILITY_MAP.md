# Nova → Nexus OS Capability Map

This doctrine describes capability and authority. Current facts must come from
the live truth view and TruthKernel-backed readers.

| Capability | Status | Nova use |
|---|---|---|
| Canonical runtime/system health reads | IMPLEMENTED / DEVELOPMENT_TESTED; real status is source-dependent | Read and explain with freshness and uncertainty |
| Active Operator state and receipts | IMPLEMENTED / REAL_WORLD_PROVEN_BOUNDED | Read-only interpretation; no direct activation |
| Governed work orders and approvals | IMPLEMENTED / REAL_WORLD_PROVEN_BOUNDED | Submit bounded requests; Nexus validates |
| Client/company reads | IMPLEMENTED / DEVELOPMENT_TESTED | Governed, privacy-bounded reads only |
| Reports and runtime artifacts | IMPLEMENTED / DEVELOPMENT_TESTED | Read with provenance; stale reports are not authority |
| Direct Nexus mutation/execution by Nova | DISABLED | Never bypass Nexus or TruthKernel |
| Payments, trading, production mutation | DISABLED / NOT AUTHORIZED | Must remain blocked |

Nexus owns eligibility, approval, execution, verification, receipts, and
canonical operational truth. “Configured,” “loaded,” “running,” and “healthy”
remain separate states.
