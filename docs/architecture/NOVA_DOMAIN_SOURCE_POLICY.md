# Nova Domain-Aware Source Policy

Nova selects evidence by the subject of Ray’s question. Verification means
using evidence appropriate to the claim; it does not mean querying Nexus.

| Domain | Preferred sources | Avoid as default |
|---|---|---|
| Nexus operations | TruthKernel, runtime, heartbeat, receipts | Public web |
| Client data | Governed Supabase/business records | Process registry |
| Internal research | Alpha artifacts, research ledger, reports | Generic Nexus health |
| Public business/company research | Public web, primary and independent sources, Alpha | Nexus runtime |
| Website analysis | Supplied site plus independent public evidence | Nexus runtime |
| General knowledge/business | Nova reasoning; current public sources when needed | Nexus operational state |
| Economics | Current evidence plus explicit assumptions; Alpha | Unverified counters |

Domains may be combined. For example, onboarding strategy can use internal
client evidence plus outside examples and Alpha analysis. Domain classification
is advisory metadata only; capability allowlists, privacy controls, cost policy,
and TruthKernel authority remain enforced below Nova.

Free/private/already-approved research is preferred. A failed source should
lead to another authorized source when useful; paid or consequential paths are
not selected silently.
