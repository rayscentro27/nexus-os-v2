# Hermes Capability Application Architecture

Hermes 0.20.6 is shared runtime infrastructure, applied selectively:

| Capability | Nova | Nexus | Alpha | Active Operator | Action |
|---|---|---|---|---|---|
| Sessions | high-value continuity | limited | useful research continuity | not required for every cycle | USE_NOW / SHARE |
| Memory | scoped conversation context | not factual authority | scoped research context | bounded runtime state instead | USE_NOW |
| Profiles | Nova role/persona | operator/worker roles | research role | bounded internal profile | USE_NOW |
| Skills | explanation, delegation, company context | execution, verification, receipts | research, source challenge, economics | allowlisted loop skills | SHARE |
| Bot Mode | delegated compound work only | bounded workers | compound research | governed worker execution | WRAP |
| Kanban/workers/handoffs | only for delegated work | operational queue boundary | compound research | scheduled bounded work | KEEP |
| Model/provider routing | conversational depth/cost | advisory only; authority stays deterministic | research route | optional advisory reasoning | SHARE |
| Gateway/API | human interface backend | runtime capability | research backend | worker backend | KEEP |
| Routines | future proactive briefs | command scheduling | research cadence | existing scheduler | DEFER expansion |
| MCP/web/browser | only bounded delegated use | never unrestricted | public research only | not required | DEFER/WRAP |

TruthKernel owns facts, approvals, eligibility, credentials, state transitions, and receipts. Hermes interprets, plans, delegates within allowlists, and explains. Nexus deterministic executors validate every claimed result.
