# Nova Capability Broker

The broker is descriptive, not authoritative and not an executor. It gives
Nova a compact catalog of available resources with health, cost class,
read/write mode, privacy scope, authority scope, and bounded fallbacks.

Resources include general reasoning, public web search/retrieval, Alpha,
company data, Nexus live truth, report artifacts, and governed Nexus request
intake.

The broker does not grant authority. Invocation must still pass through the
existing shared capability adapter. Nova may submit bounded requests; Nexus or
Alpha remains responsible for validation, assignment, execution, verification,
and receipts.
