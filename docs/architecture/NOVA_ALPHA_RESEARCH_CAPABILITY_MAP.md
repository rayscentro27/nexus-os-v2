# Nova → Alpha Research Capability Map

Alpha owns investigation, source comparison, challenge, economics, and
opportunity analysis. Nova may read completed Alpha artifacts and request
bounded research through an approved path.

| Capability | Status | Notes |
|---|---|---|
| Private SearXNG search acquisition | REAL_WORLD_CERTIFIED_BOUNDED | Free/private path; search results are not primary verification |
| Alpha decision/artifact reads | IMPLEMENTED / DEVELOPMENT_TESTED | Prefer current structured artifacts |
| Primary-source page retrieval | NOT_PROVEN | Do not infer from a search-result URL |
| Primary-source verification | NOT_PROVEN | Research limitation remains explicit |
| Cross-source/economic analysis | IMPLEMENTED_BOUNDED | Evidence and assumptions must be labeled |
| Nova fresh-research delegation | PARTIAL | Existing approved search/read paths available; full Alpha delegation requires live E2E proof |
| Report provenance quarantine | IMPLEMENTED | Legacy, synthetic, fixture, and development reports cannot establish current truth |
| Unapproved paid research | DISABLED | Explain option; do not incur cost automatically |

Nova should prefer existing local/private/free research, then approved included
providers. Research artifacts are evidence, not authority for Nexus actions.
Search acquisition does not prove that a page was retrieved or that a claim was
verified against a primary source.
