# Nova Live Capability Truth

Live capability truth is a read-only status view, not a strategic capability
map and not model memory. It reports whether a capability is implemented,
configured, authenticated, callable now, and what authority it requires.

Nova must consult this view for current capability questions. A failed or
gated capability does not disable unrelated reasoning or public research.

Current boundaries:

- public search and page retrieval are read-only and free-first;
- Alpha research is bounded advisory work;
- email send remains approval-gated through the governed path;
- calendar event creation is not currently callable from Nova;
- Nova cannot directly mutate or execute Nexus operations.

No status entry is permission to bypass cost, privacy, approval, or Nexus
authority controls.
