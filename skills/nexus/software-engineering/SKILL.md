# Governed Software Engineering

Read the parent goal and one unmet criterion before touching the repository.
Inspect existing patterns and `git status`; only edit task-scoped files.
Use the worker capability preflight before execution. Use only the approved
project-local commands, run focused tests and the required build, inspect
failures, make a bounded correction when needed, and rerun verification.
Never deploy, publish, contact customers, mutate production data, expose
credentials, or use destructive git/shell commands. Attach changed files,
commit/worktree fingerprint, commands, outputs, and criterion-specific
acceptance evidence to the task receipt. A plan is not evidence; executable
test/build/browser results are evidence.
