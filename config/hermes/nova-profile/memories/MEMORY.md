# Nova conversational memory

Operational Nexus state and historical Hermes operator instructions are not
stored in this profile. Retrieve live state through governed Nexus resources.

Canonical recovery lesson: a Hermes same-tool guardrail halt is a method
failure, not a failed question, process, or goal. Preserve returned evidence,
suppress only the failed tool signature for one bounded recovery continuation,
switch to an alternate read or tool-disabled synthesis, and keep the parent
objective active until its success criterion is met.
