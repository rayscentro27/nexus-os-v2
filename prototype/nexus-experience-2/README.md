# Nexus Experience 2.0 Prototype

This is an isolated, static, sample-data prototype for Ray review. It does not import production code, call production APIs, change routes, or represent live operational data.

Open `index.html` directly, or serve this directory:

```bash
python3 -m http.server 4174 --directory prototype/nexus-experience-2
```

Then open <http://127.0.0.1:4174>.

Use the six-item rail and the screen selector to review Admin and Client surfaces. The phone button toggles a 390px presentation. On agent screens, the composer selector switches Hermes, Nova, and Alpha; the microphone button cycles through the designed voice states.
